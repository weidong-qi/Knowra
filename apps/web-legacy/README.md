# V3 前端源码归档

本目录保存已退役的 V3 源码和回归测试。现役前端统一位于 `apps/web`，不要在此新增产品功能或恢复开发、生产启动入口。

保留归档是因为回归测试仍覆盖历史行为与共享核心的兼容契约。现役前端不得导入这里的模块或资源，该边界由架构检查维护。

从仓库根目录执行 `npm run test:web:legacy` 可运行归档测试；它继续随完整测试及 CI 执行。包名为 `@study-accelerator/web-legacy`，归档版本不再参与正式应用版本一致性校验。

目录职责见[历史源码导航](../../docs/已归档/前端/V3源码导航.md)。将仍有价值的回归迁至现役前端或共享包、核对调用方后，可以在独立清理任务中删除归档；本次只搬迁并保留原文件。
