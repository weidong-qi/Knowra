# 本轮质量审查收尾总结

## 范围与结论

本轮按职责和可验证风险推进 31 批串行治理，第 31 批以现役结构导航、文档语义门禁和本总结收尾。前 30 批已合入 main；本批独立审查、最终提交 CI 与合并状态以关联 PR 为准，不预写“全部通过”。基线为 PR138 合并提交 `170947fe9e8f3f35af1ce4602c22da3b64d9ea9c`。

主要收益是让编辑器、工作区、AI、知识应用服务、同步传输和共享纯规则各自承担明确职责，并修复审查中实际复现的并发、只读和恢复问题。不是全仓逐文件审计，不保证全仓零 bug；文件行数减少也不等于功能正确或性能提升。结构说明见[项目结构导航](../项目结构导航.md)；项目级变更统一记录在[工程变更日志](../工程变更日志.md)，各批详细说明和原工程记录保留在本专题。

## 收益分层

- **结构收敛：**编辑器保留页面接线与会话所有权，完整生命周期归入相应 hooks；AI 的纯契约/上下文与执行分离；知识模块装配不再混入导航策略、空间和笔记依赖用例；同步引擎保留连接与状态机所有权，HTTP 细节独立；附件客户端整体组合；content-anchor 内部直依实现、公共出口无反向依赖。
- **算法与重复计算优化：**题库、目标、历史来源和快照标签在请求或校验范围内复用必要索引，标签使用量由三个 UI 入口复用单遍计数。证据包含扫描/操作计数、冻结旧实现或随机差分；不宣称未经测量的整机速度提升，也不增加跨请求缓存。
- **功能修复：**检查器只读写入限制与迟到详情隔离；公式往返与粘贴边界；保存队列发送前复核、修订快照及恢复草稿保护；滚动恢复会话隔离；附件初始化和失效预览；关联目标读取同步拒绝；助手来源预览和工作区加载的迟到成功/失败隔离。具体问题与断言见相应 PR 和日志，不能将纯重构都称作修 bug。
- **诊断与验收修正：**PR134 只采集 Mac 退出阶段白名单日志、进程与合成页面现场。PR137 将文首空行删除用例的光标前置条件明确化，是测试修正，不是底层 Home 键问题的根因修复。
- **维护导航：**现役 API 调用、CmdK、编辑器、tokens 等入口不再导向退役 V3；V3 详表明确只供历史回归，已归档或移除的探索资料不伪装当前目录。有限语义门禁同时防止“路径存在但指向旧实现”和不存在的入口。

## 验证范围与边界

各批按改动选择单元、组件、注册 API runner、共享包、脚本和真实 SQLite/HTTP 回归；涉及输出等价的模块使用调用轨迹、错误顺序、冻结输入或差分用例。合成事务能验证仓库绑定与失败传播，但不能替代真实 PostgreSQL；浏览器合成响应不能替代真实供应商或用户资料验收。

仓库 CI 提供 Node 24 生产构建/架构边界、全套 npm 测试、真实 PostgreSQL 条件套件、桌面运行时 Chromium 页面、隔离容器，以及适用的 Mac 打包/原生检查。每条工作流的触发、跳过与最终状态应按对应 PR 的精确 head 核查，不能把某一批的绿灯泛化为所有平台、所有功能已验证，也不把测试数相加当作覆盖率。

第 31 批只修改文档和文档测试；本地文档链接/语义用例 3 项通过，完整脚本套件 107 项通过、2 项因未配置独立 PostgreSQL 环境跳过，差异空白检查通过；最终 CI 记录在本批 PR。不接触用户 Mac、部署、真实资料或付费模型，不发布新版本。

## 仍未解决与明确暂缓

1. **Mac 退出偶发超时：**同一源码树曾有正常退出超过 45 秒的失败，根因未明。PR134 保留原失败判定并增加诊断；后续 green 不能证明已修复。需要再次复现时结合现场定位，不能靠延长门槛或强杀算通过。
2. **编辑器 Home 前置条件：**PR137 只稳定了具体测试的选区设置；没有证据证明底层 Home 定位问题根因已解决。
3. **依赖风险：**此前生产依赖审计仍有 2 项 low；高危门禁通过不等于零漏洞。未在本批升级依赖，后续需按实际 advisories 和兼容性处理。
4. **暂缓细拆：**AI catalog 的授权与界面投影交织，过细切片收益不足；local-data-relations 包含有顺序的校验和原地修复，深拆有行为风险。workspaceSlice 剩余 mutations、workspace-api 其他领域和少量 CLI 入口判定重复保留，待明确需求或证据再处理。
5. **保留原子与平台边界：**不为行数切开 entity-sync-state/SQLite 原子状态所有权；缺少 Mac 原生证据时不拆 desktop main。V3、生成物、schema、类型和图标等不按普通业务行数机械治理。

本轮到第 31 批停止新增治理批次。上述风险是交接边界，不是默认授权继续扩展；后续以可复现问题、产品需求或明确的新审查范围启动。
