# 同步面板与桌面能力补齐

基线：`e5bd376a`。本轮只改代码与合成验证，不安装、分发或连接用户真实资料。

## 同步面板

- [OneDrive 同步状态和暂停/恢复](https://support.microsoft.com/en-us/onedrive/how-to-pause-and-resume-onedrive-sync)：顶部先给状态，再给暂停或恢复这类具体操作。
- [Dropbox Sync & storage](https://help.dropbox.com/sync/sync-storage-dashboard)：问题、进行中状态与常用操作同层可见，细节放在单独区域。
- [Nextcloud 桌面客户端](https://docs.nextcloud.com/server/stable/user_manual/en/desktop/usage.html)：自建服务可以手填地址，但日常显示已连接服务及状态，不反复展示登录表单。

知境采用同样的层级，不模仿已有 SaaS 登录。未连接时显示离线可用和一次性连接表单；连接后只先呈现状态、服务地址、最近同步与操作；暂停后提供恢复，验证失败时直接显示凭据入口。设备编号、恢复记录、待同步明细下沉，原有草稿锁、地址/资料身份绑定、恢复确认及保护备份不改变。

## 桌面能力与验收口径

- 分析范围：离线保存、移入回收站、恢复，使用已有 SQLite 写入和实体同步语义。
- 新建自定义空间：未绑定服务的本地库可以创建；已绑定时遵循远端能力和资料归属约束。兼容性不足或同名保留原件，不自动覆盖、合并。App 可以做本机迁移预览，不提交迁移；同名空间的自助解决仍待补齐。
- ZIP：提供供网页版导入的资料库导出，不等于可在 App 内恢复的原生完整备份。继续保留完整备份的导入及恢复入口。
- 原生与线上验收尚未执行；重点用无生产数据的首次连接失败/修正、数据库重启、两端同步与旧版兼容验证。反复核对主状态不被重复 aria-live 公告，凭据及诊断仅在需要时显示。

## 仍需单独接通的高风险写入

1. 网页 ZIP 恢复：以私有暂存预检及新资料库切换为基线，先保护本机数据库、附件、待同步队列和草稿，再接入恢复确认与同步暂停；不能把现有 Web 替换接口直接接给桌面。
2. 彻底删除笔记／清空笔记回收站：先做单项云端权威预检和确认。绑定当前 owner、资料世代、对象版本及影响范围；收到真实墓碑才报告完成；请求丢响应时读结果，不重新删除。单项可靠后再做批量清理。
3. 删除空间／整包迁移：空非默认空间删除及非空空间迁移分开；一次事务完成、保持备份/冲突/两端重启语义，不将跨空间迁移拆作若干离线改字段请求。

### 单篇笔记永久清理验收补充

- **过期确认反例。** 测试设备 A 预览回收站中的合成笔记。B 恢复、编辑、再把同一 ID 移回回收站。A 用旧确认提交时必须收到“资料已变化，请重新预览”，不得删除笔记、版本、标注或附件。对最终态仍为“在回收站”的情况不可只查布尔值；再加一组不改正文的恢复→再回收，防止把正文哈希当成生命周期版本。
- **事务边界。** 新的严格入口在 JSON 和 PostgreSQL 删除事务内比对 owner、资料世代、权威版本和影响范围；不能只在事务外或浏览器上检查。不要把 PostgreSQL 原有的附件列表一致性检查当作用户确认版本。检查共享附件引用；物理文件清理由既有机制在数据提交后处理。优先用权威同步修订或等价单调版本，不能依赖毫秒时间戳唯一。
- **结果确认。** 复用桌面已有联网清理的绑定检查、持久待核对记录和真实删除事实；先验证笔记及其被明确清理的依赖集合是否都受现有模型支持，再开放按钮。加入云端提交成功但未返回、客户端重启、只读重新核对的合成回归，禁止自动重发永久删除；也测旧版服务器不支持时，入口不发请求。
- 主线当前 Web 单项删除只传笔记 ID；上述为待实现验收条件，不表示现有 Web 已按用户预览校验。桌面批量清理仍不在此小步内。

### 网页 ZIP 导入验收补充

- **先打开副本，不恢复当前库。** 首版只预检 ZIP 并在独立的本地资料库中打开，不替换、合并或自动切换当前库。界面区分「打开资料库 ZIP」和「恢复完整本机备份」，前者不包含同步队列或恢复草稿。现有桌面外壳只启动一个默认资料目录，需先明确副本的独立运行和返回路径，不能把临时目录设成新的默认库。
- **不直接开放网页版恢复路由。** Web ZIP 恢复会切换附件目录，再调用存储的 `commitImport`；SQLite 会用导入内容替换快照，按普通业务写入产生删除记录和待同步项，即使未绑定也会入队。仅「未绑定」不代表安全。副本使用独立数据库、附件和草稿目录，以及不同的资料库身份；导入前先校验清单、文件字节和资料归属，成功后才展示副本。首版的副本关闭同步及自动连接，不复制当前库的绑定、队列或删除记录。 原生完整备份可供参考的是先检查再确认的流程，不是恢复执行：`finalizeRestoredDirectory` 会向候选库合并当前库的删除事实和同步归属，不能用来打开 ZIP 副本。
- **禁止副本入云，不只是暂停。** 给副本持久化「仅本机」标志，在服务端挡住连接、手动同步和后台调度；即使没有待同步队列，首次连接也会把本地与空基线比对并可能推送，连接操作还会解除暂停。ZIP 内的 owner 只是业务归属，不代表原云端身份。首版沿用兼容 owner 校验，不自动重写归属。
- **旧包反例。** 导出后，在当前库新建测试笔记及附件、永久删除一个旧 ID，并保留待同步项和草稿。预检及打开旧包后，核对当前库笔记和附件内容、删除记录、待同步项、草稿及绑定均与之前一致。旧 ID 可出现在隔离副本里，但不得回写当前库或云端。另测坏包、取消、创建失败、重启后重新打开，以及同一个包重复打开不会覆盖既有副本。
- 尚未完成桌面 ZIP 导入；以上为设计与验收条件。合并或替换当前库是另一个功能，需另做冲突、删除历史和恢复策略。

### 整包迁移验收补充

- **由云端执行，不把迁移拆成普通同步写入。** 整包迁移保留内容 ID 并改变其空间归属；普通同步禁止修改同一实体的 `spaceId`，PDF 标注另有固定字段校验。保留这些校验。桌面本机预览仅说明本机状态；执行前核对同一服务、owner、资料库世代、源和目标，取得新的云端预览。服务端在同一事务内核对资料库世代、重新计算预览并复查阻断条件。现有 Web 入口只校验预览哈希，不认桌面新增的世代和操作回执约定；桌面必须先识别新能力，不能回退到旧入口。
- **先处理未同步改动。** 首版可保守地在有未同步业务改动、草稿、冲突或附件待传输时不执行，请用户先保留并处理这些内容。不能清队列、默默覆盖，或根据本机预览继续执行。在后台同步和用户编辑可能并发时，还要核对从预览到提交的状态；另一台设备的未同步改动不能凭发起端的状态推断为零。
- **区分云端已完成与本机已更新。** 从只读权威结果核验迁移，正常拉取来更新本机。源码显示同步日志将同次事务的变更保持成组，分页不拆组，桌面接收后整体校验；实际跨空间拉取仍须测试。提交前持久记录操作与精确的受影响 ID；响应丢失时不自动再提交。通过同一操作的事务回执核对云端执行结果，再验证相关 ID、目标归属和新修订已拉取，且没有尚未解决的相关冲突。若拉取结果含冲突，桌面可能只接收无冲突记录并推进游标；游标追上不能证明整包已在本机生效。无法归因或验证则明确显示结果待核对，不能仅凭计数或源空间为空宣布成功。
- **用两台合成客户端验收。** 覆盖普通笔记与内部链接、目录、标签、附件字节、已保存分析范围，以及正常和已回收的 PDF 标注。成功后空间归属一致、ID 不变、PDF 标注版本递增、源空间保留、全局知识和训练不动，重启验证一致。再测预览后云端被编辑、本机有待同步改动、另一客户端有未同步编辑、落库后响应丢失，以及事务中途失败。当前桌面只有预览，未完成执行与两端验收。
