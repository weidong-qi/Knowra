# V3 历史源码导航

> 本文保留项目结构导航原有的 V3 章节，供旧源码和回归测试定位。V3 源码已归档至 `apps/web-legacy`，不提供开发或生产启动入口；文中的相对章节位置沿用原文，现役前端统一位于 `apps/web`，请看[项目结构导航](../../项目结构导航.md)。

## V3 历史源码导航（非现役）

以下至“共享包”前的目录与维护说明仅用于旧源码回归和迁移对照，描述的是 V3 内部职责。V3 已退役，不提供开发或生产启动入口；新增产品改动使用上方 V4 导航及下方“常见改动入口”，不得照此建立并行前端。

### `apps/web-legacy/src`

| 文件/目录 | 作用 | 状态 |
| --- | --- | --- |
| `main.js` | V3 legacy Web server 历史实现。 | 仅保留源码与回归证据；workspace 不再提供 V3 启动命令。 |
| `client.js` | 浏览器主交互入口：创建基础对象、装配 controller/actions/stateActions、绑定事件、接入运行时错误和启动加载。 | 约 150 行；不承载具体业务流程，新增业务能力不要回填到这里。 |
| `styles.css` | 入口样式。 | 与 `styles/` 协同。 |
| `app/` | 前端应用启动基础对象：初始 state、Rail 配置、DOM element 缓存、编辑器运行态。 | 从 `client.js` 拆出，只放启动基础结构，不写业务流程。 |

维护规则：

- `client.js` 只负责应用启动、依赖装配、controller 初始化、事件绑定入口和运行时错误接入。
- 新增浏览器端业务编排优先进入 `src/controllers/*`，不要回填到 `client.js`。
- 纯规则、纯状态计算、纯 HTML 字符串仍应放在 `apps/web-legacy/lib/*`。
- `controller` 文件超过 250 行时必须自查职责；超过 400 行通常应拆成子 controller。

### `apps/web-legacy/lib/events`

事件绑定层。该目录只负责把 DOM 事件转发给事件装配层提供的依赖函数或 controller 方法，不应写 API 请求、业务规则、复杂状态变更或 HTML 拼装。

| 文件/目录 | 职责 |
| --- | --- |
