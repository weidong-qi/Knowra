# 真实概念图：渲染选型与接入

2026-11-13。隔离工作区实现，尚未发布。依据《概念层首版-开发方案》第二期和领域冻结稿 2.7：图是正式数据的投影，不是独立知识数据库。

## 选型

选择 Cytoscape.js 3.35.0。功能和长期适配优先于外观。通过 GitHub 连接器核查以下官方仓库的当前许可证，均为 MIT：

- [Cytoscape.js](https://github.com/cytoscape/cytoscape.js)，[LICENSE](https://github.com/cytoscape/cytoscape.js/blob/master/LICENSE)。通用网络可视化/图算法、方向和并行多边、样式选择器、布局扩展成熟。官方 3.35.0 包自带 TypeScript 类型，框架无关，适合 React 容器加领域适配层。
- [Sigma.js](https://github.com/jacomyal/sigma.js)，[LICENSE](https://github.com/jacomyal/sigma.js/blob/main/LICENSE.txt)，与 [Graphology](https://github.com/graphology/graphology)（[LICENSE](https://github.com/graphology/graphology/blob/master/LICENSE.txt)）配合。大图 WebGL 探索更突出，但本期更需要清楚呈现多类型关系、候选与正式状态以及关系管理，而非极限节点数。未来用性能基准证明需要大图能力后可替换渲染适配器，不迁移领域数据。
- [React Flow / xyflow](https://github.com/xyflow/xyflow)，[LICENSE](https://github.com/xyflow/xyflow/blob/main/LICENSE)。适合节点编辑器和有端口的流程编排；知识关系网络不是工作流，DOM 自定义节点的便利不抵消图布局与分析扩展的额外成本。

仅增加 `cytoscape` 精确锁定依赖，不增加 React 包装层或额外布局插件。安装源为官方 npm registry，保留依赖中的许可证。旧 SVG / d3-force 实验视图不再承担正式入口，只能从明确的“实验入口”访问；依赖暂留供实验使用。

## 边界

- `realConceptGraphModel.ts`：纯数据转换，读取 conceptStore 的概念、关系及 knowledgeLibrary 的知识点。复用 web-core `conceptVisibleRelations` 和 `conceptRelationProjections`，不复制关系有效性和投影规则。
- `cytoscapeAdapter.ts`：唯一渲染库边界，提供 update/select/fit/zoom/resize/destroy。渲染 ID 使用类型前缀，防止概念/边 ID 碰撞。
- `RealConceptGraphView.tsx`：加载/错误/空态、筛选、选择与详情跳转、缩放控制、等价的可键盘访问概念与关系列表。React 卸载清理监听器、ResizeObserver 和 Core；数据更新复用实例，拓扑不变不重排。
- 正式入口 `/knowledge/graph?concept=<id>`；概念详情与图互跳。点击关系可查看依据知识点、去概念详情管理关系或确认候选。实验独立 `/knowledge/graph/experiment`。

## 数据语义

已删除、合并和归档概念不展示；不关注默认隐藏，可显式开启。关系必须两端可见且依据有效。正式已确认关系实线；主体到提及的条目投影虚线，默认显示并可关闭，保留每条依据的独立身份，只在详情确认后产生正式关系。对称关系不画箭头；其他类型保留方向。没有学习证据时全部“未评估”，不沿用实验的模拟掌握颜色。

## 资源与验收

布局不启用常驻力模拟或动画：小图有限迭代 cose；超过 250 节点用 grid，避免在用户 Mac 上启动昂贵布局。此阈值是保守工程保护，不是性能承诺。大图布局/聚合/视窗化另做基准后演进。

新增纯适配单测覆盖生命周期、过滤、方向、多边、候选开关和不写回；UI 小测验证受控更新、缩放和卸载。遵循 AGENTS.md：本机不跑浏览器、构建、全套回归或 PostgreSQL。完整类型检查、真实 Canvas 页面行为和跨端回归需推送至隔离分支后在 GitHub Actions 验证。局部检查不能替代完整验收。
