## 功能闭环

1. 在概念详情建立关系，选择终点、七类关系之一，可选择同时挂靠两端的知识点作依据；没有依据时明确作为手工骨架。
2. 由已确认主体→提及挂靠派生待定类型提示，只读计算、无新增集合或后台写入。用户选择类型并确认后才调用现有关系命令，保留该条知识点作为依据。同一依据已有确认关系时不重复提示；对称关系考虑反向。
3. 关系可以编辑、删除。编辑保存冲突保留输入，明确核对新版本后重试。相同提交复用操作 ID，防止成功但响应丢失后的非幂等重试。删除前显示方向、类型和依据。
4. 真实图读取概念三集合及知识点列表，渲染器替换为 Cytoscape.js，不继续使用旧实验绘图。正式已确认边实线，投影虚线。两端、依据或挂靠失效时过滤；不关注默认隐藏可开启，已删除/合并/归档概念不展示。全部掌握状态为未评估。
5. 概念页、图、知识点依据互跳，图可缩放并提供键盘可访问列表；刷新重新读取两类来源。旧实验仅保留在 `/knowledge/graph/experiment`，其原有测试同步迁移。
6. 定义知识点按主体挂靠和最早创建选择，直接展示正文，其他定义折叠；挂靠管理仍可进入。尚未实现原第一期方案的“写定义并自动挂靠”单独入口，目前可先创建知识点再挂入。
