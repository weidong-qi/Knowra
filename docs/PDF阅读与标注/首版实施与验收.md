# PDF 阅读与标注首版

## 使用范围

PDF 作为独立资料导入，单文件最大 **50 MiB（52,428,800 字节）**。资料库“新建 → 导入 PDF”一次选择一个文件，可查看进度和取消；同目录重名顺延。已有笔记内的 PDF 附件保留原归属。

沿用资料树、标签页、收藏、标签、移动、回收站和资料路由。类型筛选区分笔记、PDF、文件夹。阅读页支持连续滚动、页码跳转、缩放、适合宽度、旋转、目录、文档内搜索及复制文字。窄屏通过“标注”切换侧面板。阅读位置、缩放、旋转按本机资料集及文件身份保存。

文字选择后“高亮选区”可保存跨页片段；“区域框选”限制在单页，适用于扫描页、图片和公式。标注复用重点／疑问／补充／易错／临时笔记及普通／重要／核心。分类、重要程度、评论自动保存；界面显示保存中、已保存与错误。并发冲突可核对最新版本，再选择保留本机修改或采用最新版本；远端已删除时，保留本机修改创建新标注。

原文件不写入批注。可下载原 PDF，或按页码和位置导出含摘录、评论、页码、内部定位链接的 Markdown；区域只导出说明及链接。PDF.js 原批注单独显示，不进入知境标注编辑。

首版不提供手写、OCR、带批注 PDF 导出、AI 内容理解、知识候选生成或全库 PDF 正文检索。扫描件可阅读与框选。密码仅在会话中使用，密码不保存、不进入同步或备份；损坏文件由阅读器显示错误。恢复原文件要求大小和 SHA-256 完全相同，修订后的文件应导入为新资料。

## 数据与模块边界

| 内容 | 实现位置与约束 |
| --- | --- |
| 资料身份 | `Note.contentKind` 为 `markdown` 或 `pdf`；缺省按 Markdown。`pdfSource` 记录 `attachmentId`、`sha256` 及导入请求摘要。资料类型及主文件不可改换。 |
| PDF 标注 | 独立 `pdfAnnotations` 集合／`PdfAnnotation` 表；保存资料、空间、附件、哈希、类型、坐标片段、原文、分类、程度、评论、修订及操作回执。 |
| 坐标 | `pageIndex` 从 0 开始；矩形存 PDF 页面坐标 `[xMin,yMin,xMax,yMax]`，由 PDF.js viewport 正反转换，避免按屏幕像素保存。高亮多个片段；区域恰好一个片段。 |
| 写入 | `operationId` 幂等、`expectedRevision` 并发检查；原文、几何和来源保存后不可重绑。删除使用标注墓碑，随资料永久删除清理。 |
| 本地恢复 | `knowra:pdf-draft:v1:` 保存待提交内容、确认基线及冻结请求。Web 用 localStorage，Mac 用受限原子草稿文件；保存、退出、备份握手复用现有生命周期。损坏草稿不会被退出清空。 |
| 服务端 | `apps/api/src/modules/pdf/` 分离文件、repository、服务、路由和 ZIP 资料包。工厂装配沿用现役 API。 |
| 阅读器 | `apps/web-v4/src/features/pdf/` 按需加载官方 `pdfjs-dist`，核心、Worker、CMaps、字体、ICC 和 WASM 随前端打包；不依赖 CDN。自有 SVG 标注叠层独立于 PDF.js 原批注。 |
| 生命周期 | 主文件纳入引用检查，不能单独删除；资料回收与恢复保留标注，永久删除进入现有协调事务及文件清理。PDF 跳过 Markdown 正文写入、版本恢复、分析范围与 AI 读取。 |

导入先流式写临时文件、完整计算哈希并校验大小，再发布文件和事务提交资料／附件。失败回滚不留下可打开的半成品。PDF 原文件传输使用二进制；普通附件保留既有限额。文件读取提供 HEAD、单段 Range、ETag 和精确 Content-Length。生产前端代理流式转发，独立执行 PDF 50 MiB 限额，普通 JSON 限额不变。

## 接口

全部 JSON 响应继续使用 `{ data }`／`{ error: { code, message } }`。Mac 请求仍绑定活动资料集，写入继续服从只读及恢复保护。

| 接口 | 行为 |
| --- | --- |
| `POST /api/storage/pdf-imports?operationId=…&spaceId=…&folderId=…&fileName=…` | 二进制 PDF；`folderId` 可省略；相同操作与相同输入返回同一资料，换文件或元数据拒绝复用。 |
| `GET / HEAD /api/storage/pdf-files/:attachmentId` | 原文件；单段 `Range: bytes=…`，无效范围 416。 |
| `PUT /api/storage/pdf-files/:attachmentId` | 二进制原文件恢复，大小和 SHA-256 必须匹配。 |
| `GET /api/pdf/:noteId/annotations` | 活跃标注列表。 |
| `PUT / DELETE /api/pdf/:noteId/annotations/:id` | 请求含 `operationId`、`expectedRevision`；首次创建为 0，后续使用确认修订。 |
| `POST /api/sync/blob-stream` | 同步二进制文件；协商与设备信息使用既有认证边界及 `X-Knowra-Blob` 元数据。 |
| `GET /api/storage/archive` | 流式 ZIP：manifest、快照、所有原文件。 |
| `POST /api/storage/archive/inspect` | 二进制 ZIP 或旧 JSON；预检后返回短期 token 和统计，不替换当前库。 |
| `POST /api/storage/archive/restore` | `{token, confirmToken}` 显式确认；恢复前保护备份，返回 `backupId`。 |
| `DELETE /api/storage/archive/:token` | 放弃预检，清理临时包。 |
| `GET /api/storage/archive/backups/:backupId` | 下载恢复前保护包。 |

Web 设置新增“资料库文件备份”，先完成保存再导出，导入须预检与确认替换。仅接受知境生成的无压缩 ZIP，逐文件校验清单、引用、owner、大小与 SHA-256，拒绝重复条目、路径穿越及不完整 ZIP。首版使用普通 ZIP，包总量小于约 4 GiB、文件数最多 65,533、元数据最多 64 MiB；更大资料库使用 Mac 完整目录备份。恢复前保护 ZIP 保存在配置的 `STORAGE_EXPORTS_DIR`，临时文件使用 `STORAGE_TEMP_DIR`。Mac 继续使用原生完整备份及资料集切换协议，包含 PDF 文件、标注和恢复草稿。
