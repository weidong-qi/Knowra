# PDF 离线查词第一版

本版面向阅读英文文献时的生词查询：本地英汉词典、选择释义、保存为普通 PDF 标注。句段翻译、语境解释和发音暂未接入；查词不会调用模型或外部词典服务。

## 使用

- 在文字选择工具下双击英文单词，打开查词卡；已高亮或加下划线的文字也可双击。
- 拖选单词或短语后，可点击现有标注工具条中的“查词”。查询接受最多 80 个字符、6 个词的英文词语，不提供整句翻译。
- 卡片显示单词、音标、释义和 ECDICT 来源；有可靠词形映射时显示原文与原形。只有英文释义的条目会明确提示。
- 默认保存全部释义，也可在“保存的释义”中只选一条；超过批注 2000 字符限制时须选择较短释义。
- “保存为标注”沿用当前高亮／下划线样式，分类默认为“补充”。批注保存本次看到的词条和释义，原文与页码位置仍由原有 PDF 标注记录持有。
- 相同位置重复保存同一份释义时定位已有标注；不覆盖已有批注。查询本身不创建标注。
- 点击卡片外部、关闭、按 Esc、滚动正文、切换工具或改变 PDF 视口时关闭查词卡。鼠标移离不会关闭卡片。
- 只读资料仍可查词，保存按钮禁用；未收录词和词库加载失败分别提示，读取失败可以重试。

保存复用 `PdfHistory`、`PdfSession` 的撤销／重做、草稿恢复、退出保存和既有同步，不引入独立生词表或新的资料格式。

## 词库与来源

- 项目：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)。
- 固定提交：`39cfb9672c0906b63569e0453c2e6abfb9ab182a`。
- 输入：该提交的 `ecdict.csv`，SHA-256 为 `d1ecbdf9ee2b920afb6f430ca6b6bb9f559588cf0dff86e04bd255f9390843cc`。
- 保留适合英文词语查询、且至少有一种释义的 761390 条去重记录。仅做大小写统一、字段抽取和原始 `\n` 换行转换，不改写词典释义。
- 按词首两个英文字母生成 701 个确定性 gzip JSON 分片，压缩后约 20.2 MiB。只按需加载，内存最多缓存 12 个分片；词形还原使用原词库的 `exchange` 原形映射。
- 上游 MIT 许可原文随数据放在 `apps/web/public/dictionaries/ecdict-39cfb967/LICENSE.txt`，由 Vite 复制到 Web 和桌面离线包。清单、来源版本和各分片 SHA-256 位于 `features/dictionary/ecdictManifest.ts`。

词库提供通用释义，不会根据论文上下文选择词义；专业术语、新词和短语可能未收录。结果均标明词典来源，不将词典查询称为语境解释。

## 维护和验收

使用 Python 3 生成资源，常规运行和构建无需 Python，也无需联网下载词库：

```bash
python3 scripts/dictionaries/build_ecdict.py
# 也可通过 --source 指向已下载的同一版本 CSV；输入仍须通过固定哈希检查。
node scripts/lint/run.mjs prettier --write apps/web/src/features/dictionary/ecdictManifest.ts
node --test scripts/test/ecdict.test.js
```

`localDictionary.test.ts` 覆盖规范化、真实词形映射、中文／英文释义、缓存及重试；`PdfDictionaryPopover.test.tsx` 覆盖释义选择、只读、空结果、失败和迟到请求。`pdf-dictionary.test.mjs` 使用合成 PDF、真实鼠标双击与无外部请求的环境验证保存去重、撤销重做、重开和悬停预览。

## 双击标注与查词联动

双击选词后的同一张卡片同时显示词典结果和普通标注操作，可直接切换高亮/下划线、选择分类。普通标注保留选区原文；“保存为标注”沿用将选中释义写入补充标注的路径。未收录或词库读取失败不阻止普通标注；只读资料隐藏新增标注操作。操作区复用现有选区分类条的卡片内布局，避免两个定位浮层重叠。
