# PDF 句段翻译

面向阅读外文文献时的整句、整段翻译，与[离线查词](离线查词.md)互补：单词走本地 ECDICT 词典，句段走已配置的大模型。

## 使用

- 在文字选择工具下拖选句子或段落，选区工具条点击“翻译”。不会自动翻译：只有点击时才把选中文字发送给模型。
- 英文等外文译为简体中文；以中文为主的选区译为英文。服务端会合并 PDF 断行和连字符断词。
- 卡片提供“复制译文”“保存为标注”“查看原文”，并复用查词卡里的高亮/下划线和分类操作。保存沿用当前标注样式，分类为“补充”，批注内容为 `翻译 · 模型名` 加译文；超过批注 2000 字符时只能复制。
- 单次最多 3000 字，超出时提示分段，不发送请求。关闭卡片、滚动、按 Esc 或切换工具会中止进行中的请求。
- 只读资料也可以翻译，但不能保存。未配置模型、未启用外发、预算用完或已暂停时显示原因，不提供重试；网络或供应商错误可重新翻译。

## 服务端

- `POST /api/ai/translate`，请求体 `{ text }`，须带 `X-Knowra-AI-Translate: 1`。成功返回 `{ data: { translation, sourceText, targetLanguage, modelId, truncated } }`。
- 桌面入口沿用本地会话与同源校验，并要求请求绑定当前资料集；资料库已切换或正在恢复时拒绝旧请求。
- 实现位于 `apps/api/src/modules/ai/translation-service.ts`，由 AI runtime 装配（`runtime.translation`），不读知识库、不带工具。`translation-tasks.ts` 复用 JSON / SQLite / PostgreSQL 的 AI 任务与调用记录，在预算预留前落盘调用 ID，发送前记录状态；只保存元数据与哈希，不保存选区原文或译文。
- 提示词把原文放在 `<source>` 中，并要求模型只翻译、不执行原文里的指令。
- API 与桌面宿主启动时，将当前资料集中断翻译的预留恢复为“结果未知”，保留预算占用并显示到用量页，用户可沿用现有入口确认费用或释放。恢复不会重发模型请求，且会跳过当前实例仍在执行的翻译；结算失败保留任务供下次恢复重试，已结算或已释放的账目不改写。关闭 AI 时中止并等待翻译和恢复收尾后再关库。
- 资产永久清理预检将合法翻译任务识别为无知识库资产引用，并核验空来源范围、无工具授权与任务引用绑定。翻译历史不会阻断无关手工知识或训练资产的永久删除；损坏记录仍要求修复，清理资产也不删除翻译历史或预算账目。
- 费用与助手共用 `deepseek-primary` 预算账本：按最坏情况预留，返回后按实际 token 结算；请求已发出但失败时记为“结果未知”，与助手一样在用量页处理。客户端断开会中止模型请求。

## 测试

- API：`apps/api/test/ai-translation.test.js`（文本规整、方向判断、预算结算、失败处理、HTTP 接口；子进程在预留前、预留后、发送后及结算后退出，重新打开资料库验证启动恢复和用量处理；可选 PostgreSQL 重连回归）。
- 跨功能：`apps/api/test/authoritative-asset-purge.test.js` 与 PostgreSQL 对应用例，覆盖真实合成翻译完成/失败、重新打开资料库后清理无关知识及四类训练资产，并验证损坏引用仍阻断。
- 前端：`apps/web/src/features/pdf/PdfTranslationPopover.test.tsx`（译文展示与保存、只读、重试、超长与中止）。
- 桌面：`apps/desktop-runtime/test/local-budget-authority.test.mjs` 验证翻译预留后进程退出、SQLite 重启恢复和真实用量接口释放；`apps/desktop-runtime/test/runtime-server.test.mjs`（翻译请求头、资料集绑定）与 `test/e2e/pdf-translation.test.mjs`（真实 PDF 选区、桌面接口、合成模型、译文保存与重新打开；不调用真实模型）。
