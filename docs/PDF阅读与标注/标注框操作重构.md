## 已确认的交互规则（2026-11-16）

原始说明和截图保留如上。以下为本次重构采用的完整边界。

| 入口 | 行为 |
| --- | --- |
| 侧栏卡片的摘录、评论和空白区域 | 选中并定位正文标注，同时显示对应批注窗口；不自动聚焦正文输入框 |
| 侧栏浅灰评论区 | 始终显示；双击进入行内编辑，未选中的卡片也可直接编辑；键盘可用 Enter / F2 |
| 正文高亮、下划线、区域、便签 | 单击显示原有操作栏，再次单击同一标注收起；关闭操作栏后保留选中 |
| 操作栏的编辑批注按钮 | 显示该标注的批注窗口并聚焦输入 |
| 正文标注上的右键 | 显示批注窗口并聚焦输入；触控板使用系统的双指轻点，不是连续双击 |
| 正文单词连续双击 | 保留原有查词与翻译行为；查词、AI 翻译仍需手动点击保存按钮创建批注 |
| 重叠标注 | 先选具体标注，再执行本次入口的操作；右键选择后进入编辑，鼠标主按钮选择后显示操作栏 |

### 窗口、预览与连线

- 同时只打开一个批注窗口；正文选择 B 不会把已打开的 A 窗口切走，明确编辑 B 或点击侧栏 B 才替换。
- 窗口固定在 PDF 阅读视口内，可拖动标题栏调整位置；滚动、缩放、旋转、点击空白均不关闭窗口。每条标注的窗口位置仅在本次打开 PDF 期间记忆，重新打开后重置。
- 便签图标仍拖动便签本身；窗口标题栏只拖动窗口，不改标注坐标。窗口标题栏支持方向键移动，Shift + 方向键微调。
- 批注预览跟随鼠标，保留移入预览后阅读、滚动与复制的能力，以及 300ms 离开宽限。当前窗口对应的标注不再重复预览，其他标注仍可预览；空批注不显示预览。
- 鼠标停在当前窗口或对应标注时，显示最近可见标注片段与窗口边缘的连线；指针离开或标注离屏时隐藏。连线不拦截正文操作，并随滚动、缩放、旋转、窗口拖动更新。
- 点击“完成”、关闭按钮或按 Esc 可关闭窗口。Esc 先关闭查词卡内的释义下拉等最内层浮层，再关闭查词卡或操作栏、结束侧栏编辑，最后关闭正文窗口；中文输入法合成期间不处理关闭快捷键。

### 保存、权限与回归范围

- 正文和侧栏共用同一份批注草稿与原有 450ms 自动保存队列，不新增第二份编辑缓冲；保存失败保留草稿、重试和并发核对流程。
- 只读状态可查看、选中与复制批注；不能修改内容、分类或标注位置。删除或撤销导致当前目标消失时，关闭该目标窗口。
- 本次不修改后端接口、持久化结构或数据库，不新增作者、回复线程和 WPS 样式。
- 实现拆分为独立交互状态、窗口组件、侧栏评论组件与连线几何计算；页面回归使用合成 PDF 和临时 SQLite 数据，不操作真实资料库。
- 重型验证在 GitHub Actions 执行；本地仅做格式、ESLint、差异检查与少量轻量定向单测。
