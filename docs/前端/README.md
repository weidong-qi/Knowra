# 前端设计资料

当前可启动的前端代码位于 `apps/web`，npm workspace 名称为 `@study-accelerator/web`。工程与组件约定见[开发规范](../开发规范.md)，代码入口见[项目结构导航](../项目结构导航.md)。

| 目录 | 职责与说明 |
| --- | --- |
| [V5](V5/) | V5 视觉演进草案（[知境视觉规范-V5-草案.md](V5/知境视觉规范-V5-草案.md)、[笔记页面设计.md](V5/笔记页面设计.md)、[Inspora 面板与交互设计参考](V5/Inspora面板与交互设计参考.md)）、[底稿](V5/底稿/)原型与[实施计划](V5/实施计划/)分阶段验收；历史草案的状态与数值需结合后续决策和当前实现核对。历史文档里的 `apps/web-v4` 和 `@study-accelerator/web-v4` 记录当时的路径与工作区名称，现分别对应 `apps/web` 和 `@study-accelerator/web`（阶段性 `web-v5` 目录也已统一更名）。 |
| [V5 图标源](V5/knowra-icons-v2/) | 当前 Knowra 图标的数据源（`icons-v2.mjs`）、预览与生成脚本（`build-tsx.mjs`），仍用于维护 `apps/web/src/components/icons/knowra/`，不属于纯历史资料。 |

| [归档](归档/) | 本目录内已沉淀或被替代的早期设计稿（含 `knowra-icons-v1` 旧版图标源码、印格阶段样式原型与早期品牌概念图）。 |
