# 前端设计资料

当前可启动的前端代码位于 `apps/web`，npm workspace 名称为 `@study-accelerator/web`。工程与组件约定见[开发规范](../开发规范.md)，代码入口见[项目结构导航](../项目结构导航.md)。

- [V5](V5/) 保存视觉演进草案、原型和阶段验收；草案中的历史状态与数值需要结合后续决策和当前实现核对。历史文档里的 `apps/web-v4` 和 `@study-accelerator/web-v4` 记录当时的路径与工作区名称，现分别对应 `apps/web` 和 `@study-accelerator/web`（阶段性 `web-v5` 目录也已统一更名）。
- [V5 图标源](V5/knowra-icons-v2/icons-v2.mjs)与生成脚本仍用于维护前端图标，不属于纯历史资料。
- [品牌](品牌/) 保存品牌标志、设计探索与交付素材；目录中的 HTML 选型稿保存具体设计探索。
- [设计系统开发版](设计系统开发版/README.md) 保存从 Claude 设计系统导出的133个源文件、现橙浅色、深色主题和本地组件预览工程；支持本地自动刷新，原始备份保留在仓库外，不会自动写回产品前端。
- [历史前端资料](../已归档/前端/README.md)保存印格、V3 原型和 V4 重构时的方案、报告与证据。
