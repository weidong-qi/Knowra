# 雾光藏馆 · 可交互设计预览

基于 2026-11-17 视觉探索中第一张显示的浅色方案制作。独立静态页面，无安装、构建或后端依赖。

直接用浏览器打开本目录的 `index.html` 即可。`style.css` 管理视觉规则，`app.js` 管理演示数据与交互，`assets/` 包含三张透明文件夹插画和复用的知境图标。

支持资料集切换、跨资料集搜索、收藏筛选、名称/时间排序、紧凑列表、新建演示笔记、资料详情、标注弹层、阅读预览及浅深色切换。左下角的设置图标切换主题。窄屏隐藏侧栏和详情，点击资料直接打开阅读预览。

本页面使用 8 篇示例资料。新建与收藏变更仅保留在当前页面内存中，刷新恢复；阅读内容是排版示意，不加载真实 PDF 或个人资料。工作域轨道的其他图标仅展示外观。

视觉规则：冷白正文表面、浅蓝灰导航；蓝色集中于主操作和选中态；三张文件夹作为资料集识别物；文字、计数与操作由 HTML 渲染；阴影以接触层次为主，悬停仅轻微抬升。深色模式是同一套布局的补充探索。

浏览器检查与对照见 `design-qa.md`。正式产品源码未修改。
